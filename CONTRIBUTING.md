# Contributing to Awesome Data Systems

Thanks for your interest in contributing! 🎉  
This project is a community-curated list of databases, data systems, and related tools. We welcome contributions of new entries, improvements to descriptions, new categories, and resource links.

---

## How to Contribute

1. **Fork** the repository and create a new branch.
2. **Add or edit entries** in the appropriate section of `README.md`.
   - Use the following format:
     ```markdown
     - [ToolName](https://example.com) - Short, clear description (max 1 sentence).
     ```
   - Descriptions should be **objective and concise** (no marketing language).
3. **Keep alphabetical order** within each category.
4. **Submit a Pull Request (PR)** with a clear explanation of the change.


## Contribution Guidelines

✅ **Do:**
- Add tools, frameworks, or resources relevant to the data ecosystem.
- Keep descriptions short, neutral, and informative.
- Add new categories if a group of tools doesn’t fit existing ones.
- Link only to official sites or documentation.

❌ **Don’t:**
- Add duplicate entries.
- Add promotional/affiliate links.
- Add tools without a homepage, documentation, or repo.


## New Categories

If you propose a new category:
- Make sure it has at least **2–3 entries** to start with.
- Add it to the **Table of Contents**.
- Provide a short category description for consistency.
